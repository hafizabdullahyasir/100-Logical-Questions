## 🎯 The Mission

This repository is built on **two core pillars**:

**1. 🌍 Build a multi-language problem archive**
Every problem solved here should exist in as many programming languages as possible. Same logic, different syntax. Python, C++, Java, Go, Rust, Swift — bring your weapon of choice.

**2. 🧠 Learn deeply, not just solve**
Every solution comes with dry runs, debugging notes, and conceptual breakdowns. The goal isn't to submit code — it's to *truly understand* it.

> *"Don't just run the code. Understand what the machine is doing."*

## 🤝 How to Contribute

Contributing is simple — no experience with the repo required!

### Step-by-Step

```bash
# 1. Fork this repository (click "Fork" button top right)

# 2. Clone your fork
git clone https://github.com/YOUR-USERNAME/100-Logical-Questions.git
cd 100-Logical-Questions

# 3. Create a new branch
git checkout -b feat/question-01-python

# 4. Add your solution file
# e.g., question-01.py

# 5. Commit and push
git add .
git commit -m "feat: Question 01 in Python"
git push origin feat/question-01-python

# 6. Open a Pull Request on GitHub ✅
```

### ✍️ Solution File Template

Every solution file should start with this header (adapt to your language's comment style):

```python
# ================================================
# Question 01: Find all prime numbers in an array
# Language   : Python
# Author     : Your Name (@YourGitHubHandle)
# Approach   : Brief description of your logic
# Time       : O(n√n)
# Space      : O(k) — k = number of primes found
# ================================================

def find_primes(numbers):
    # Your solution here
    pass

print(find_primes([2, 4, 6, 8, 5, 11]))  # [2, 5, 11]
```

### PR Title Format
```
feat: Question XX in [Language Name]
```
Example: `feat: Question 01 in Python`
